# Anti-AFK Jump Roblox

A simple AutoHotkey script that automatically presses the Space key.

## Requirements

- Windows
- AutoHotkey v1.1

## How to use

1. Download the `.ahk` file from this repository.
2. Double-click it to run the script.
3. Press **F6** to start, **F7** to stop, or **F8** to toggle it on or off.

By default, the script presses Space every 50 milliseconds.

## Note

Only use this where automated input is allowed. Behavior may vary between games.
